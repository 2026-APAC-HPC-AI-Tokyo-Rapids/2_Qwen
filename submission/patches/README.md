# Changes carried by the submitted stack

Paths outside `submission/` refer to the accompanying repository, which is required for rebuilding the image. Runtime patches are text copies numbered in application order; their source paths remain canonical. No kernel or patch content was changed for this package.

Source reconstruction starts from public [sgl-project/sglang](https://github.com/sgl-project/sglang) `0d6bef6b6d2f4fa03187fb4d02773ad6e1256adb` (shallow fetch). Its tree `9ea4c7300d38bd9e024330b45bf5fc9cbf70f97d` is identical to the team mirror’s rewritten-history boundary `6b3506869d4840b18678de19d18d751a34f9b737`, which does not exist upstream. `build/sglang-6b350686.commit` is the raw original commit object; `git hash-object -t commit -w` recreates it exactly, and it is marked shallow. The bundle then adds the three team commits, reconstructing `fc275674a97d78553b22597ee72c8fd48f5420f4` exactly without private repository access. The three extra commits remove upstream CI, lock `python/uv.lock`, and add/update a mirror workflow. DeepGEMM host sources are public `sgl-project/DeepGEMM` v0.1.5 (`1c8138a59b3df5dac50b76b730834ed57982fdfb`); its ordered JIT-header and host patch series are separate. Router sources are the pinned PyPI `sglang-router` 0.3.2 source distribution. FA3/CUTLASS source pins and compiler flags are in `kernels/fa3-verify/build.py`.

Classes: **bit-identical** means the same operations and order; **FP-order** means the same operations with changed floating-point summation or FMA order; **no numeric effect** means scheduling/runtime/build metadata. **to confirm** explicitly marks cases where the patch's history/research does not establish one of those classes. A class does not certify the organisers' full-set accuracy check. Optional companion candidates remain listed even when the pinned run does not select them.

The basis column names the exact patch commit to inspect with `git show`/`git log`, or a repository research note. In particular, the selected Prefill N192 and Decode split-attention paths are not claimed bit-identical to the stock attention geometry. The rejected wide QK-norm overlay is absent. Image build order is the SGLang array in `scripts/build-sglang-container.sh`, then the DeepGEMM `series` files and the Dockerfile steps. Runtime order is each numbered overlay directory (14 SGLang, 7 DeepGEMM).
