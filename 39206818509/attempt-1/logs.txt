40-50 us.

every rounding step are unchanged, so the output must be byte-identical to
the image kernel: the bench hashes are compared, and the SGLang check runs
check_prefill_attention (bitwise unfused-reference/paged/contiguous checks)
on the candidate tree.

PDL/index variants.

configs/firmus-framework.json since 19d8a61), which already carries the
prologue; the candidate differs from it only by this patch. Its result
decides whether the patch joins the overlay serving run on the main image.
