2026-10-18T03:46:48.5695581Z   QWEN_COMMIT_MESSAGE: Add a default-off patch so idle Prefill ranks use the Prefill MegaMoE geometry

M3 found that an idle Prefill DP rank (0 local tokens) allocates a 1-row
output, so DeepGEMM 0.1.5 (num_tokens = y.size(0)) picks the Decode SwapAB
geometry while the other ranks run the Prefill geometry; the idle rank then
processes the other ranks' ~24k token-expert pairs with Decode tiles (3.29
ms/layer) and the busy ranks' layers stretch from 1.74-1.83 to 2.12 ms. The
host heuristic selects BLOCK_M 128 / 512 epilogue threads when
rows * ep_size * topk / num_experts >= 64, i.e. 256 rows for EP4/top-8/128.

patches/sglang/megamoe-idle-prefill-geometry.patch: with
SGLANG_MEGAMOE_IDLE_PREFILL_GEOMETRY=1, in disaggregation prefill mode and
only when the local token count is 0, run_sm90_mega_routed allocates 256
output rows. Pre-dispatch still runs with num_tokens=0, so every top-k slot
of the symmetric buffer is -1; the kernel's dispatch skips -1 slots and its
combine stores zeros for rows without valid slots (also after the late-topk
patch); y[:0] is returned. The 256-row config equals the busy ranks'
instance (same block, waves, barriers), so no new JIT compile. Decode is
untouched. Precision: same FP8 inputs and weights; only the FP32 tiling of
the idle rank's work changes, which removes the mixed-geometry rounding
difference (allowed by the updated precision policy).

GPU gate (scripts/check-firmus-megamoe.py), only when the switch is 1: case
idle-prefill-rows ([4096, 4096, 4096, 0], idle rank with 256 rows) compares
busy ranks against the FP32 reference with the existing tolerances and
requires the idle rows to be zero; then times the same collective with 1 vs
256 idle rows (prefill-one-idle-1row / -256rows). Both instances are already
compiled by existing cases. With 0 the gate is unchanged.

sbatch: export SGLANG_MEGAMOE_IDLE_PREFILL_GEOMETRY=0 job-wide (gate and
workers inherit it; the code acts only in Prefill mode), worker.sh exports
SGLANG_DP_TOTAL_REQUESTS_ROTATE_TIES=0 for Prefill and
SGLANG_DECODE_ASYNC_ADMISSION=0 for Decode, and the startup line prints all
switches. Tests pin the off defaults so enabling one is a tracked commit.
scripts/check-firmus-tier2-source.py `idle-geometry` runs the patched wrapper
with DeepGEMM mocked (256 rows only for idle Prefill with the switch on).
