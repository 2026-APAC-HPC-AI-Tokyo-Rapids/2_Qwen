# Fixed EP1 Prefill routing helper

One CUDA TU, three integer kernels. B512 input tiles histogram 128 experts, one CTA computes expert totals and per-tile exclusive offsets, tile-local shared cursors scatter routes. No cross-CTA cursor atomics, no GEMM/CUTLASS templates or floating-point arithmetic. Existing wheel GEMMs and FP8 quantize-once/shuffle/SwiGLU/BF16 down/combine remain in place.

Production opt-in `SGLANG_PREFILL_TILED_ROUTING=1`: Prefill/Hopper/EP1, BF16 target input, FP8 blockscale128, E128/top8/H4096/I384/T<=8192. All production IDs must be valid 0..127; invalid-ID filtering in helper-only tests is not whole-MoE support. Expert row order was non-deterministic in the original atomic helper; new integer tile offsets are deterministic but intra-tile shared atomics need not preserve that order. Map inverse/count/prefix invariants and full output quality are required, not raw map equality to stock.

Each histogram bucket and local cursor is reset on every invocation. Counts/tile offsets are fully overwritten before consumption on the same current CUDA stream, no CPU device-count synchronization. T0 helper resets all count/offset metadata; the Python caller skips the whole MoE before maps/backend allocation. No padded rows are introduced; offsets retain unrounded EP1 row counts. Buffers are allocated from CPU shape metadata and CUDA graph capture reuses allocation.

CPU: `uv run --project qwen-experiment-metrics pytest qwen-experiment-metrics/tests/test_prefill_routing.py qwen-experiment-metrics/tests/test_prefill_routing_probe.py`. These do not establish compilation or GPU correctness. Fixed FC private patch chain: SiLU -> draft selected-head -> FP8 paired shuffle -> tiled routing. The organizational mirror is read-only.

Finite external one-GPU probe `scripts/benchmark-prefill-moe-routing.py`: stock/tiled same image, wheel GEMMs/shuffle on, 20 alternate/reversed paired rounds, 100 timed graph replays and >=200ms contiguous warmup. Standalone map/count invariants and wholeMoE quality are hard gates. Training T8192 balanced/skew requires each >=0.5% median improvement and >=15/20 faster pairs. Heldout T4096 skew/T8192 hot-only/T65 tail must have no median regression. T32 dense BF16/FP32 reference baseline envelope, finite/relativeL2<=1e-3 vs wheel and bitwise diagnostics, changed-route same-graph reset, helper/whole T0 are checked. Failures stop; no online tuning or automatic adoption. Synthetic routing is not an observed production expert histogram. E2E is still required after a promising micro result.

Observed old P profile measures count39.870ms plus scatter114.717ms /5.004391sec (~3.09% active). Eliminating both is an upper sensitivity bound, not a gain forecast. Existing IDs may hit L2; O(ER)->O(R) logical reads do not directly imply HBM reduction. New image is mandatory even though only one helper TU is built. Same-new-image off/on official E2E must hold all other conditions fixed.
