These 396 completed runs are proposed for removal only after owner approval. Native job summaries cannot be edited after upload. Sanitized logs, original run IDs/conclusions/timestamps and job/step records are retained here; complete raw originals are stored in a restricted private backup. Native HTML summaries are not copied as HTML.

The scope combines 317 runs with literal private identifiers in summary-writing commands, 63 further runs with a summary writer and private data in the same job log, 18 runs with private run metadata (6 overlap the first group), 3 expired managed-review runs that cannot be inspected, and 1 run with a private path in a persisted check annotation. The other 147 completed runs with expired logs have 135 available source snapshots, none containing a repository job-summary writer.

No queued or running run is included. The 83 retained hosted artifacts belong to other runs.
