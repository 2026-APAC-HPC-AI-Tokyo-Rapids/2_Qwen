## 2. Stage-0 admission (8d26550) changed nothing measurable

| run | first PP0 microbatch | first 2-request microbatch | `#bootstrap-req` at the first microbatch | burst intercept | < 3 s |

- **The change works as designed.** At the first microbatch the bootstrap queue is now empty, and 69 requests wait in the waiting queue.

- **So the round-8 attribution was wrong.** The Decode bootstrap was not what held the first microbatch back. What sets the 0.29 s, the one-request first microbatch and the 216 ms gap is still open.
- AIPerf sends the 232 burst requests within 89 ms of the phase start.

## 3. The tail-wave skip (4bc07dc) lost its in-job gate

Per GPU: medians of 15 interleaved rounds of 20 calls, QKV + O pair at M = 7988.

| worker | stock (µs) | skip (µs) | skip − stock (µs) |
|---|---|---|---|
| prefill-0 | 961.0 / 961.0 / 953.9 / 965.8 | 1025.1 / 1020.8 / 1017.2 / 1029.2 | +64.1 / +59.9 / +63.3 / +63.4 |
| prefill-1 | 949.7 / 958.6 / 957.4 / 957.1 | 1010.2 / 1018.8 / 1017.5 / 1015.4 | +60.6 / +60.2 / +60.1 / +58.3 |
| prefill-2 | 974.2 / 966.6 / 980.8 / 973.0 | 1035.0 / 1029.9 / 1044.8 / 1041.4 | +60.8 / +63.3 / +64.0 / +68.4 |

- **Correctness held, speed did not.**
  - Every GPU passed byte equality with stock at M 7988 and 3994, the FP32 reference check, and 200 endurance calls.
  - The skip was **6.3% slower** on all twelve GPUs, about +62 µs per pair.
  - The aggregate kept stock. Each selector took 29–30 s.
- **This is the same sign and order as round 2** (7eb80b0: +12% with a stagger plus the tail skip). The tail skip alone is enough to lose.
  - The skip removes 2.34% of the MMA work, yet costs 6%. So the in-loop branch costs more than the work it removes: one predicate per wave inside the k-block loop, +144 static instructions.
  - Removing padding work inside the 1D2D mainloop by a runtime branch does not pay. Do not retry it in this form.
- The header and host patch are unused at their default. They are removed again so the image does not carry a losing path.
